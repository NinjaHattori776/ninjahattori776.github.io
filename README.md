# Hashir Tariq — Portfolio

Personal portfolio website built with React + Vite, hosted on GitHub Pages.

🌐 **Live site:** https://ninjahattori776.github.io

## Tech Stack
- React 18 + Vite
- Pure CSS (no external UI library)
- GitHub Actions for CI/CD
- GitHub Pages for hosting

## Sections
- **Hero** — animated matrix rain + typing effect
- **About** — bio, education, work experience
- **Projects** — 22+ projects with category filter
- **Skills & Certifications** — full tech stack + certs + awards
- **Contact** — links to email, LinkedIn, GitHub, Medium

## Local Development

```bash
npm install
npm run dev
```

## Deployment
Pushes to `main` automatically trigger the GitHub Actions workflow which builds and deploys to GitHub Pages.
